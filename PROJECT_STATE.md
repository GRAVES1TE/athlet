## 📌 О проекте

- **Стек:** Ванильный HTML5, CSS3, JavaScript (ES6+), Web Audio API, Service Worker / PWA manifest.

## 🎯 Выполненные задачи и исправления

### 1. Исправление критического бага с окнами и вылезанием тренировки снизу
- **Причина проблемы:** В HTML класс модального окна был `workout-modal` (`#workoutPlayerModal`), а в стилях использовался `.workout-player-modal`. Из-за этого плеер тренировки не скрывался стилями, находился в общем потоке документа и отображался в самом низу страницы под навигацией. Также элементы отдыха (`.rest-overlay`) не были скрыты.
- **Что сделано:**
  - Полностью изолированы все модальные окна (`#workoutPlayerModal.workout-modal`, `#finishModal.finish-modal`, `#exerciseInfoModal.exercise-info-modal`): по умолчанию они гарантированно скрыты (`display: none !important; pointer-events: none; visibility: hidden; position: fixed; top: -99999px;`).
  - При активации (`.active`) они выводятся как фиксированные полноэкранные оверлеи с плавным открытием (`position: fixed; inset: 0; z-index: 9999-10000; height: 100dvh;`).
  - Добавлено корректное управление оверлеем отдыха (`.rest-overlay.hidden` скрыт `display: none !important;`).

### 2. Исправление размеров, верстки и переполнения (Overflow & Sizing)
- **Что сделано:**
  - На `html`, `body` и `.app-container` жестко задан `overflow-x: hidden; width: 100%; box-sizing: border-box;`. Ни один элемент больше не вылезает за пределы ширины экрана (нет горизонтального скролла).
  - Сетка карточек тренировок: добавлен класс `.workout-info` с `min-width: 0; flex: 1;`, заголовки и описания аккуратно усекаются (`text-overflow: ellipsis`, 2 строки максимум для текста описания), теги не ломают ширину карточки.
  - Календарь активности: сверстана точная 7-колоночная сетка (`.calendar-weekdays`, `.calendar-grid`, `.cal-day`, `.cal-day.today`, `.cal-day.done`, легенда с точками) под генератор из `app.js`.
  - Экран настроек: исправлен макет строк (`.settings-row`, `.setting-info`, `.setting-title`, `.setting-desc`), плавные iOS-слайдеры переключателей выровнены по правому краю без смещений.
  - Экран библиотеки упражнений: элементы `.exercise-guide-item` сжаты по ширине контейнера с безопасным усечением текста (`.guide-details`, `.guide-name`, `.guide-target`).
  - Верхняя панель (Stats Bar): сбалансированы отступы и размеры плашек (`.stat-pill`), прогресс-бар уровня плавно масштабируется на любых экранах от 320px до десктопа.
